# DoForMe - 任务圈 / 共识集市

## 📋 项目简介

DoForMe是一个基于地理位置与社交关系的去中心化任务协作与轻量级价值交换平台。用户可以像发朋友圈一样发布任务，像使用多币种钱包一样管理信用资产，用自己发行的"个人货币"或团体币奖励他人，构建独特的社交价值网络。

**技术栈**: HarmonyOS ArkTS
**开发状态**: 开发中 (85%完成)

## 💡 核心概念

### 三层货币体系

1. **世界币 (Shell)** 💎
   - 平台官方货币，1:1锚定人民币
   - 全平台通用，可充值提现

2. **个人币 (Star)** 👤
   - 用户自发行，基于个人信用
   - 朋友网络流通

3. **团体币 (Guild)** 👥
   - 团体管理员发行，团体内部共识
   - 封闭流通，用于内部激励

### 核心功能

- ✅ **任务系统** - 发布、接取、执行、验证
- ✅ **商店系统** - 店铺管理、商品兑换
- ✅ **消息系统** - IM聊天、消息推送
- ⏳ **货币系统** - 铸造、转账、交易
- ⏳ **LBS功能** - 地理位置、附近任务
